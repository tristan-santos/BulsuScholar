# BulsuScholar Documentation Index

This folder contains project documents that are not required by the running system.

## Folders

- `testing/` - Alpha testing guidelines and tester-specific V1/V2 test cases.
- `diagrams/dfd/` - Data Flow Diagram text files.
- `diagrams/erd/` - ERD text export.
- `migration/` - Supabase/Python migration notes and debugging checklists.
- `deployment/` - Hosting and deployment checklists.
- `planning/` - TODO and planning notes.
- `email/` - Email template notes.
- `capstone/` - Capstone guide documents.
- `reference/` - General reference notes.

Runtime files were left in their original locations, including `src/`, `backend/`, `public/`, `supabase/`, `api/`, `scripts/`, and deployment config files.
